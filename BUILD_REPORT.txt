================================================================================
USAGE EXAMPLES
================================================================================

1. Analyze Data:
   aws-migrate analyze --source json --path samples/mongo_export.json

2. Plan Migration:
   aws-migrate plan --analysis-file analysis.json --record-count 1000

3. Dry Run:
   aws-migrate migrate --plan-file migration-plan.json \
     --source samples/mongo_export.json --s3-bucket test-bucket \
     --dynamodb-table test-table --dry-run

4. Execute Migration:
   aws-migrate migrate --plan-file migration-plan.json \
     --source samples/mongo_export.json --s3-bucket prod-bucket \
     --dynamodb-table prod-table

5. Validate Results:
   aws-migrate validate --s3-bucket prod-bucket \
     --dynamodb-table prod-table --expected-records 1000

6. Rollback if Needed:
   aws-migrate rollback --manifest-file default-migration-manifest.json
